两数之和 II · 有序数组 中等部分通过 5 / 8

P0005 · 通过率 71% · 提交 5 次 · 最快 15 ms

题目描述

给定一个已按升序排列的整数数组 numbers，请你找出两个数，使其相加等于目标值 target。函数应返回这两个数的下标（从 1 开始计），且下标 1 < 下标 2。可以认为每组输入只有唯一解，且同一个元素不能被使用两次。

1示例

输入：numbers = [2, 7, 11, 15], target = 9
输出：[1, 2]
解释：2 + 7 = 9，因此返回 [1, 2]
输入：numbers = [2, 3, 4], target = 6
输出：[1, 3]
输入：numbers = [-1, 0], target = -1
输出：[1, 2]

2约束

2 ≤ numbers.length ≤ 3 × 10⁴ · -1000 ≤ numbers[i] ≤ 1000 · numbers 按非递减顺序排列 · -1000 ≤ target ≤ 1000 · 仅存在一个有效答案

3提示

数组已经有序，可以使用双指针技巧：左指针从数组开始，右指针从数组末尾开始，根据两数之和与目标值的比较调整指针位置。时间复杂度 O(n)，空间复杂度 O(1)。

class Solution: def twoSum(self, numbers: List[int], target: int) -> List[int]: # 双指针：从两端向中间逼近 left, right = 0, len(numbers) - 1 while left < right: s = numbers[left] + numbers[right] if s == target: return [left + 1, right + 1] elif s < target: left += 1 else: right -= 1 return [] # 测试代码 if __name__ == '__main__': sol = Solution() print(sol.twoSum([2, 7, 11, 15], 9))
