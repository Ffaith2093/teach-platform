F(0) = 0，F(1) = 1
F(n) = F(n-1) + F(n-2)，其中 n ≥ 2

给定一个整数 n，请输出 F(n) 的值。

输出格式

一行，包含一个整数，表示 F(n)

输出

n = int(input())

def fib(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n):
        a, b = b, a + b
    return b


print(fib(n))
