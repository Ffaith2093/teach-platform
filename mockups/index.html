def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        diff = target - n
        if diff in seen:
            return [seen[diff], i]
        seen[n] = i

沙箱自动评测

容器 --network=none --read-only 隔离，判 AC / WA / TLE / MLE，学生提交后秒级拿到结果。

以班级为单位的派发

作业、试卷、资源一键派发到整个班级，无需让学生手动输入邀请码；转班时引用自动迁移。

客观题秒判 + 主观题精批

单选 / 填空 / 代码填空自动判分，编程题展示自动评测 + 老师可覆盖；批改页支持键盘上下切换学生。

组卷 + 抽题规则

支持固定组卷和按标签 / 难度抽题规则两种模式，预览生成结果再发布，组卷逻辑可复用到不同班级。

考试分析自动出

分数分布直方图、题目通过率、区分度、高频错误一次出齐；班级成绩趋势可按周 / 月 / 学期查看。

审计与合规

所有账号由管理员创建，学生按班级批量导入；账号状态机与权限校验在每次请求入口处强制走通。
