教师参考答案

思路：哈希表一次遍历，O(n) 时间 O(n) 空间。

def twoSum(self, nums, target):
    seen = {}
    for i, n in enumerate(nums):
        c = target - n
        if c in seen:
            return [seen[c], i]
        seen[n] = i
    return []

题目描述：编写一个函数 dedup(lst)，去除列表 lst 中的重复元素，保持元素出现的原始顺序，返回新列表。

不能使用 set 直接转换（会丢失顺序）。

样例输入：

1 3 2 4

教师参考答案

使用 set 记录已出现元素 + 列表收集结果。

def dedup(lst):
    seen = set()
    out = []
    for x in lst:
        if x not in seen:
            seen.add(x)
            out.append(x)
    return out

教师参考答案

正则切词 + Counter 统计。

def top_words(path, k=10):
    with open(path, encoding="utf-8") as f:
        text = f.read().lower()
    words = re.findall(r"[a-zA-Z一-鿿]+", text)
    return Counter(words).most_common(k)
